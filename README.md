# En webbsida för MDU
## Med hjälp av vibecoding
Vibecoding är ett verktyg/arbetssätt där man använder AI för att skapa en artefakt.

Arbetsättet är alltså att skriva vad man vill ha för resultat och sen så fixar AI det.

Här använder vi AI för att bygga up vår egna webbsida för MDU studenter som går i kursen ITE130
