Faktaruta

Vad är Git?

Git är ett versionshanteringssystem som hjälper dig att hålla ordning på ändringar i kod och andra filer. Det är användbart både när du arbetar själv och tillsammans med en grupp.

Historik Spara ändringar som commits och se hur projektet har utvecklats.
Parallellt arbete Skapa branches för att prova nya idéer utan att ändra huvudversionen.
Samarbete Dela och sammanfoga ändringar med verktyg som GitHub eller GitLab.
